# SuperMemo Assistant Import plugin

Imports web pages, browser tabs (Chrome and Firefox, through the browser extension and its native messaging host), and RSS/Atom feeds into SuperMemo.

This plugin is part of [SuperMemoAssistant 20 Community](../../../README.md), which runs on SuperMemo 20 (64-bit) and .NET 10. It is bundled with the installer.

The original plugin is [supermemo/SuperMemoAssistant.Plugins.Import](https://github.com/supermemo/SuperMemoAssistant.Plugins.Import).

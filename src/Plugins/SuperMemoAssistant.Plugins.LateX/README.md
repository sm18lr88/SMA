# SuperMemo Assistant LaTeX plugin

Renders LaTeX formulas in SuperMemo elements.

This plugin is part of [SuperMemoAssistant 20 Community](../../../README.md), which runs on SuperMemo 20 (64-bit) and .NET 10. It is bundled with the installer.

The original plugin is [supermemo/SuperMemoAssistant.Plugins.LateX](https://github.com/supermemo/SuperMemoAssistant.Plugins.LateX).
